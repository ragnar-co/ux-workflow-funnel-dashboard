# UX/UI Reference Only

This directory contains source material from the user's previous Ragnar NPS Web App project.

Use it for:
- layout patterns,
- spacing,
- design tokens,
- sidebar/topbar/card/table/modal patterns,
- upload-preview-validation interaction ideas,
- reusable React presentation components where appropriate.

Do NOT use it as source of truth for:
- NPS metrics,
- NPS entities/aggregates,
- survey bounded contexts,
- old `ddd-web-app` architecture,
- project business rules for UX Workflow Funnel Dashboard.

The source of truth for the new project is `ddd-data-analytics/reference/` plus `docs/analytics/`.
